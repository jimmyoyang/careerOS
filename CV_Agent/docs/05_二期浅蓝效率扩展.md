# 二期：浅蓝效率扩展

## 1. 阶段目标

二期建立在一期数据模型和基础投递闭环上，增加多网站适配、批量处理、Outlook只读同步、提醒和统计能力，降低用户在大量岗位申请中的重复操作。

## 2. 二期范围

| 模块 | 交付内容 |
|---|---|
| M17 | 支持不同校园招聘和社会招聘系统的页面适配 |
| M18 | 批量读取、解析和排序岗位 |
| M19 | 批量填充低风险字段并逐条生成确认任务 |
| M20 | 只读读取Outlook中的投递和面试邮件 |
| M21 | 截止时间、笔试、面试和补材料提醒 |
| M22 | 申请数量、岗位类型和状态统计 |
| M09增强 | 支持精准、平衡和覆盖模式的批量任务 |

## 3. 二期流程

```text
选择招聘网站和岗位范围
→ 批量读取岗位
→ 去重和硬性条件筛选
→ 根据投递模式排序
→ 生成逐岗位材料任务
→ 批量填充低风险字段
→ 用户逐条确认
→ 同步邮件和后续节点
```

## 4. 二期边界

批量处理只生成和推进投递任务，不替用户完成验证码和最终提交。Outlook只申请读取权限，不申请发送邮件权限。
