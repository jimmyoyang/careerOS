# 数据来源、数据模型与接口

## 1. 数据来源

| 数据来源 | 主要数据 | 获取方式 | 阶段 | 用途 |
|---|---|---|---|---|
| 校园招聘官网 | 校招岗位、批次、JD和申请入口 | 浏览器读取用户主动打开的页面 | 一期 | 岗位采集和正式投递 |
| 社会招聘官网 | 社招岗位、JD和申请入口 | 浏览器读取用户主动打开的页面 | 一期 | 岗位采集和正式投递 |
| 招聘平台页面 | 岗位列表和岗位详情 | 浏览器读取当前页面 | 一期/二期 | 补充岗位来源 |
| 用户手动输入 | 岗位链接、JD和公司信息 | 粘贴文本或链接 | 一期 | 页面无法解析时的兜底 |
| 用户资料库 | 教育、实习、项目、技能和语言信息 | 用户填写或导入 | 一期 | 岗位匹配和简历生成 |
| Outlook | 投递确认、笔试、面试和拒信 | 用户授权只读访问 | 二期 | 自动更新申请状态 |
| 招聘群和文档 | 岗位、内推链接和招聘批次 | 用户导入或复制内容 | 三期 | 补充岗位来源 |
| 公开内推信息 | 公司、批次、岗位和内推码 | 用户发起搜索或粘贴来源链接 | 三期 | 内推候选信息 |

## 2. 核心数据对象

| 对象 | 关键字段 | 说明 |
|---|---|---|
| UserProfile | 用户身份、学校、专业、城市、求职方向 | 维护用户基础资料和偏好 |
| EvidenceItem | 经历、日期、职责、数字、技能、证据 | 作为简历生成的事实来源 |
| SiteConnection | 官网URL、网站类型、授权范围、访问状态 | 管理招聘网站连接 |
| JobPosting | 公司、部门、岗位、地点、批次、链接、JD原文 | 记录岗位基础信息 |
| JDAnalysis | 职责、要求、技能、限制、关键词 | 保存JD结构化解析结果 |
| MatchResult | 匹配分、可信度、证据、风险、建议 | 记录岗位判断结果 |
| ResumeVariant | 模板、版本、修改内容、编译结果 | 管理岗位定制简历 |
| Application | 投递状态、时间、材料、来源、下一步 | 管理正式投递 |
| Communication | 邮件主题、时间、分类、原文入口 | 管理投递相关邮件 |
| ReferralLead | 内推码、来源、发布时间、适用范围、确认状态 | 管理公开内推候选 |
| AuditEvent | 操作人、操作类型、字段变化、时间、结果 | 保存审计记录 |

## 3. 内部接口

| 接口 | 请求内容 | 返回内容 | 阶段 |
|---|---|---|---|
| `POST /site-connections` | 官网URL和授权范围 | 连接ID和页面状态 | 一期 |
| `POST /browser/pages/snapshot` | 页面URL、类型和页面快照 | 页面识别结果 | 一期 |
| `POST /jobs/ingest` | 岗位文本、链接和来源 | 标准化岗位记录 | 一期 |
| `POST /jobs/{id}/parse` | 岗位ID和JD原文 | JD结构化结果 | 一期 |
| `POST /matches` | 岗位ID、资料版本和投递模式 | 匹配分、证据和风险 | 一期 |
| `POST /resume-variants` | 岗位ID、事实库版本和模板 | 简历生成任务 | 一期 |
| `POST /latex/compile` | LaTeX文件和编译配置 | PDF、错误、页数和日志 | 一期 |
| `POST /applications/{id}/form-scan` | 页面快照和申请记录 | 表单字段映射 | 一期 |
| `POST /applications/{id}/fill-preview` | 字段映射和用户确认 | 填充预览结果 | 一期 |
| `POST /applications` | 岗位、简历版本和投递信息 | 投递记录 | 一期 |
| `POST /mail/sync` | 邮件授权和同步范围 | 邮件分类与状态候选 | 二期 |
| `POST /referrals/search` | 公司、批次和岗位关键词 | 内推候选列表 | 三期 |

## 4. 系统事件

| 事件 | 触发条件 | 后续处理 |
|---|---|---|
| `job.ingested` | 岗位进入系统 | 标准化和去重 |
| `jd.parsed` | JD解析完成 | 进入匹配流程 |
| `match.completed` | 匹配完成 | 生成推荐结论 |
| `resume.generated` | 简历内容生成 | 启动LaTeX编译 |
| `compile.failed` | 编译失败 | 返回错误位置并暂停 |
| `form.needs_confirmation` | 页面包含高风险字段 | 等待用户确认 |
| `application.submit_requested` | 用户报告点击提交，但尚无网站结果 | 保存为待核验，不等同于投递成功 |
| `application.submitted` | 获得成功回执或核验网站申请记录；用户手动确认单独标记验证方式 | 保存验证依据和方式后更新投递台账 |
| `application.submit_failed` | 网站返回明确提交失败 | 保存失败原因，不能标记已投递 |
| `mail.status_candidate` | 邮件识别出投递事件 | 等待确认或记录候选状态 |
| `referral.candidate_found` | 找到公开内推信息 | 等待用户确认来源 |

投递结果需保留验证方式、结果来源、发生时间、申请标识和去重键。用户手动确认使用 `user_attested`，系统获得网站证据使用 `site_verified`；事件重复不创建重复申请。详细状态与实施验收见 [一期实施与验收任务台账](10_一期实施与验收任务台账.md)。
