# 三期：浅绿智能扩展

## 1. 阶段目标

三期扩展招聘群、腾讯文档、表格和公开内推信息来源，并基于历史投递数据形成更个性化的岗位推荐和投递策略。

## 2. 三期范围

| 模块 | 交付内容 |
|---|---|
| M23 | 导入招聘群消息、腾讯文档、Excel和CSV |
| M24 | 根据用户输入的公司、批次和岗位搜索公开内推信息 |
| M25 | 记录内推码来源、发布时间、适用岗位和用户确认状态 |
| M26 | 同步电脑、手机和浏览器的工作台数据 |
| M27 | 根据历史投递和面试结果调整岗位推荐 |
| M28 | 生成岗位面试准备和沟通材料 |

## 3. 内推信息流程

```text
用户输入公司和招聘批次
→ 搜索近期公开内容
→ 提取公司、岗位、批次和内推码
→ 记录来源链接和发布时间
→ 生成可信度说明
→ 用户确认
→ 加入投递记录
```

公开内推信息只能作为候选来源。系统不能仅凭公司名称和一串邀请码判断其有效性。
