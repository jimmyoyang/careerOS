# 全量功能模块与优先级

## 1. 优先级定义

| 优先级 | 含义 | 进入阶段 |
|---|---|---|
| P0 | 没有该能力就无法完成该阶段的核心闭环 | 必须实现 |
| P1 | 能够显著提升效率，但不阻塞基础闭环 | 一期后优先实现 |
| P2 | 扩大来源、增强智能策略或支持规模化使用 | 三期及以后 |
